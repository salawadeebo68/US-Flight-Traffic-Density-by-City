# US-Flight-Traffic-Density-by-City
Math DS Final Project US Flight Traffic Density by City January 2026

โปรเจควิเคราะห์และสร้างแบบจำลอง Machine Learning เพื่อหาเมืองศูนย์กลางเมืองการบิน  ในสหรัฐอเมริกา ประจำเดือนมกราคม 2026

## ไฟล์ในโปรเจค
การวิเคราะห์เมืองที่มีความหนาแน่นของเที่ยวบิน.ipynb ไฟล์โค้ดหลัก
T_ONTIME_REPORTING.zip ไฟล์ข้อมูลเที่ยวบิน


1. **เตรียมไฟล์:** แตกไฟล์ (Unzip) `T_ONTIME_REPORTING.zip` จะได้ไฟล์ `.csv` 
2. **อัปโหลด:** นำไฟล์ `.ipynb` และไฟล์ `.csv` ทั้ง 2 ไฟล์ ไปเปิดใน **Google Colab** หรือ Jupyter Notebook ในโฟลเดอร์เดียวกัน
3. **รันโปรแกรม:** กดรันโค้ดจากบนลงล่าง (Run All)
